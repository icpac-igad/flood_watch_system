KEY SERVICES & WHAT THEY DO
============================

1. FASTAPI SERVICE (fastapi-service/main.py)
   - Serves deterministic forecast GeoJSON from Impact_mergeddeterministicgeojson
   - Endpoints:
     GET /api/fast/merged-forecast/dates/           [cached 15 min]
     GET /api/fast/merged-forecast/{date}/          [cached 1 hour]
     GET /api/fast/merged-forecast/latest/          [cached 30 min]
   - Features: AsyncPG pooling, ORJSON serialization, country filtering
   - Per-request timing logs for monitoring
   - 979 features per forecast date

2. STAC API SERVICE (stac-api/main.py)
   - Metadata catalog service using stac-fastapi-pgstac
   - PgSTAC extension enabled for STAC storage
   - Currently EMPTY - no collections or items registered
   - Endpoints:
     GET /collections
     GET /collections/{id}/items
     POST /search (spatial/temporal)
   - Ready to ingest but not configured yet

3. TIPG SERVICE (tipg-service/main.py)
   - Vector tiles OGC Features & Tiles API
   - Auto-discovers PostGIS tables:
     - Impact_admin0, Impact_admin1, Impact_admin2 (boundaries)
     - Impact_waterbodies, Impact_hydrorivers (geography)
     - Impact_monitoringstation (monitoring stations)
   - Serves MVT vector tiles + GeoJSON features
   - Built-in tile viewer included
   - NOT YET EXPOSED in docker-compose

4. DJANGO BACKEND (backend/Impact/)
   - GeoJSON ViewSets via Django REST Framework
   - Endpoints: /api/admin0/, /admin1/, /admin2/, /water-bodies/, etc.
   - Models for spatial data (geometry fields via GeoDjango)
   - EnsembleControlPoint model for merging forecast data
   - Authentication: BasicAuth (staging) + JWT (disabled)
   - CORS enabled for all origins (should restrict in production)

DATABASE MODELS & TABLES
========================

FORECAST DATA:
- Impact_mergeddeterministicgeojson
  Columns: id, data_date, date_string, geojson_data (JSONB), feature_count, 
           file_count, created_at, updated_at, processed_by
  Use: Stores complete 979-feature forecast GeoJSON per day
  Indexed by: data_date, date_string, created_at

ENSEMBLE:
- Impact_ensemblecontrolpoint
  Columns: id, GRIDCODE (unique), zone, geometry (Point)
  Use: Reference points for merging ensemble forecast with control points

BOUNDARIES & GEOGRAPHY:
- Impact_admin0, Impact_admin1, Impact_admin2 (admin boundaries)
- Impact_waterbodies (lakes, rivers)
- Impact_hydrorivers (river network - 283,806 segments)
- Impact_monitoringstation (gauge stations with thresholds)

RASTER:
- Impact_alertlevelraster (alert level COGs)
- Impact_floodhazardmapraster (inundation COGs)

AUTHENTICATION
==============

BasicAuthMiddleware:
- Staging only (STAGING_AUTH_ENABLED flag)
- Credentials: username/password via Authorization header
- Exemptions: /admin/, /health/

MapAuthMiddleware:
- JWT-based (rest_framework_simplejwt)
- Protected: /api/.*geojson.*, /api/.*deterministic.*, /api/.*layers.*
- Currently DISABLED (returns None immediately)

Production: Both auth systems should be re-enabled and hardened
