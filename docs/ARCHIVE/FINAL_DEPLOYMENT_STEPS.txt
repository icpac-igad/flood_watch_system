STEP 1: COPY STATIC DATA FILES TO STAGING SERVER
=================================================

On your LOCAL machine, you need to have these files:
- Admin1.geojson (country boundaries)
- Admin2.geojson (province/district boundaries)
- Lakes.geojson (water bodies)

Copy them to staging server:

scp Admin1.geojson hkoros@41.139.151.242:/home/hkoros/eafw/data/
scp Admin2.geojson hkoros@41.139.151.242:/home/hkoros/eafw/data/
scp Lakes.geojson hkoros@41.139.151.242:/home/hkoros/eafw/data/

=================================================
STEP 2: UPDATE BACKEND CONTAINER ON STAGING
=================================================

SSH to staging server:
ssh hkoros@41.139.151.242

cd /home/hkoros/eafw

# Pull updated backend image
sudo docker-compose pull backend

# Restart backend containers
sudo docker-compose up -d backend celery celery-beat

# Check they're running
sudo docker-compose ps

=================================================
STEP 3: LOAD STATIC DATA INTO DATABASE
=================================================

On staging server, run:

# Load all static data (Admin1, Admin2, Lakes)
sudo docker-compose exec backend python manage.py load_all_static_data

# Or load individually if needed:
sudo docker-compose exec backend python manage.py load_all_static_data --skip-lakes
sudo docker-compose exec backend python manage.py load_all_static_data --skip-admin1 --skip-admin2

# To clear and reload:
sudo docker-compose exec backend python manage.py load_all_static_data --clear

=================================================
STEP 4: UPDATE FRONTEND ON STAGING
=================================================

# Pull updated frontend
sudo docker-compose pull frontend

# Restart frontend
sudo docker-compose rm -sf frontend
sudo docker-compose up -d frontend

# Check it's running
sudo docker-compose ps

=================================================
TROUBLESHOOTING
=================================================

If API errors persist:
1. Clear browser cache completely
2. Try incognito/private window
3. Check backend logs: sudo docker-compose logs backend
4. Check frontend logs: sudo docker-compose logs frontend
5. Verify backend is accessible:
   curl http://localhost:8090/api/admin1/

If data doesn't load:
1. Check files exist: ls -la /home/hkoros/eafw/data/
2. Check file permissions: should be readable
3. Run load command with verbose output
4. Check backend logs for errors
