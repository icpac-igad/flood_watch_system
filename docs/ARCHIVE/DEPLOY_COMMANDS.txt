FloodWatch v1.1-staging - Simple Deployment Steps
==================================================

STEP 1: ON LOCAL MACHINE
=========================

# Push images to Docker Hub (after docker login)
docker push hkoros/floodwatch-backend:v1.1-staging
docker push hkoros/floodwatch-frontend:v1.1-staging

# Copy files to staging server
scp docker-compose.staging.yml hkoros@41.139.151.242:/home/hkoros/eafw/docker-compose.yml
scp .env.staging hkoros@41.139.151.242:/home/hkoros/eafw/.env


STEP 2: ON STAGING SERVER
==========================

# SSH to server
ssh hkoros@41.139.151.242

# Go to directory
cd /home/hkoros/eafw

# Stop current containers
sudo docker-compose down

# Pull new images
sudo docker-compose pull

# Start new containers
sudo docker-compose up -d

# Check status
sudo docker-compose ps

# Run migrations
sudo docker-compose exec backend python manage.py migrate

# Sync flood data
sudo docker-compose exec backend python manage.py sync_floodproofs_to_db


ONE-LINER FOR STAGING SERVER:
==============================

cd /home/hkoros/eafw && sudo docker-compose down && sudo docker-compose pull && sudo docker-compose up -d && sudo docker-compose exec backend python manage.py migrate && sudo docker-compose exec backend python manage.py sync_floodproofs_to_db
